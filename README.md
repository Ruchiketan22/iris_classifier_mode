# 🌸 Iris Flower Classification using Random Forest

This project uses the popular Iris dataset to build a machine learning model that classifies iris flowers into one of three species:
- Setosa
- Versicolor
- Virginica

We use a **Random Forest Classifier** from `scikit-learn` to train and evaluate the model.

---

## 📊 Dataset

The Iris dataset consists of 150 samples of iris flowers. Each sample has 4 features:
- Sepal length (cm)
- Sepal width (cm)
- Petal length (cm)
- Petal width (cm)

Each sample is labeled with one of the three species.

---

## 🚀 What This Project Does

- Loads the Iris dataset from scikit-learn
- Splits data into training and testing sets
- Trains a Random Forest Classifier
- Predicts flower species based on new input
- Evaluates accuracy and performance of the model

---

## 📦 Libraries Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib (optional, for plotting feature importance)
